# Phishing Awareness Training

## Overview

This project is a cybersecurity awareness presentation focused on phishing attacks. It helps users understand how phishing works, how to identify fake emails and websites, and how to protect themselves from social engineering attacks.

## Contents

* What is phishing?
* How phishing attacks work
* Recognizing phishing emails
* Identifying fake websites
* Social engineering tactics
* Real-world examples
* Security best practices
* Interactive quizzes

Project File

* `Phishing_Awareness_Training_Detailed.pptx`

Objectives

* Increase cybersecurity awareness
* Help users recognize phishing attempts
* Promote safe online behavior
* Reduce the risk of credential theft and data breaches
